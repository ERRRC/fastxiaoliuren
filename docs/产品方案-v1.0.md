# 小六壬教学软件产品方案（v1.0）

> 状态：方向已定稿。本文档是开发依据，变更需回写。

---

## 0. 已锁定的决策

1. **完全免费**，无内购、无广告
2. **纯 Web/PWA**：不做小程序、不上应用商店
3. **教学型产品**：只教方法，不做排盘工具
4. 软件不替用户起课，不输出针对用户本人的任何判断

## 1. 产品原则（宪法条款）

**"教你算，不替你算。"**

用户学完之后怎么用、问什么事、做出什么判断，是他自己的事。软件只做三件不越界的事：教方法、判对错、存记录。具体边界：

- **不提供"输入问题 → 输出吉凶"的功能。** 起课引擎存在，但只藏在判卷器里——用户自己掐，软件核对对错。引擎永远不直接面向用户"出卦"。
- **不预置任何针对用户本人的内容。** 没有"今日运势"式推送，没有"你今天适合做什么"。练习题一律用中性教材式表述（"某人于某日某时测某事"）。
- **断语口诀以传统文献的身份出现。** 软件教的是"传统上这个宫位说什么"，呈现的是教材内容，不是软件在替人断事。

附带收益：这条原则让产品定位彻底干净——它就是一个传统民俗文化教学工具，合规风险降到最低。

## 2. 产品形态

一句话定位：**10 分钟教会你自己掐指起课；之后它是一本随身教材和练习册。**

产品类比：Duolingo / Wordle——练习与习惯产品，不是计算器、不是词典查询机。软件的终极目标是让用户**脱离软件、在自己手上**完成起课。

## 3. 模块结构

### 3.1 课程区（学）——获客与激活

- 虚拟手掌动画：六宫位置、掐算路径、"月上起日、日上起时"的光点演示
- "我来算"分步模式：光点慢放，用户自己点指节，软件逐步判卷
- **毕业标准：脱离虚拟手掌，在自己手上完成一次完整起课**

### 3.2 练习区（练）——产品的心脏

- **每日一练**：以"今天"的农历日期和时辰为练习题，用户自己掐、软件判卷。时辰边界显式展示（"未时，还剩 12 分钟"）。用户自己决定要不要把结果联系自身——软件不引导。
- **随机出题**：程序生成任意时间题，无限题源（六爻方案里装卦训练器的移植）
- **断语配对**：六宫 × 事类约 50 格的记忆练习

### 3.3 题库区（刷）——最低门槛的参与入口

> 决策记录：v1.0 曾以"知识量太小、题库必冗余"为由砍掉题库，后推翻。理由：刷题是中文用户零学习成本的熟悉交互，其价值不在知识覆盖而在**参与门槛**——刷题比动手掐指低一级，是漏斗最宽的口。小知识库 × 题型变换 × 程序生成 = 题量充足且不靠同义重复凑数。

**双轨制**：
- 人工题：约 150 道，覆盖全部知识点，一次性内容工作
- 生成题：起课计算题程序无限生成（农历时间 → 落宫四选一），即"随机出题"训练器的刷题化包装

**章节结构**（与知识清单一一对应）：

| 章节 | 题型示例 | 题量 |
|---|---|---|
| 1. 六宫基础 | "大安的下一宫是？"（四选一）；"留连在哪根手指？"（点指节图） | ~30 |
| 2. 宫位属性 | "速喜五行属什么？配哪位六神？" | ~25 |
| 3. 断语口诀 | 正向："速喜问求财，传统断语是？"；反向："'失物在坤方'出自哪宫？"；判断："空亡是吉宫" | ~50 |
| 4. 起课计算 | "农历三月初五酉时起课，落宫是？"（生成器无限出） | 无限 |
| 5. 情景判断 | "某人测失物落赤口，按传统断语宜？"（教材式情景） | ~30 |

**标配**：错题本（重做答对 2 次自动移出）、各章正确率统计、**段位测试**（限时 20 题，合格线 90%——科目一式；段位：学徒 → 记宫 → 掌诀 → 掐指如飞）

**宪法兼容性**：所有题干以"传统断语/口诀怎么说"的文献知识出题，不替人断事；生成题一律用中性时间表述，不出"你今天"的题。

### 3.4 内容区（查）——随身教材

- 六宫详解（总象、五行、六神、指节位置）
- 断语速查卡：按宫位、按事类两个维度检索。身份是教材/字典，不是排盘结果。
- **自测模式**：一键遮住断语答案自查背诵——速查卡的功能开关，不做成独立模块。

### 3.5 记录本（记）——用户自己的复盘

- 记录用户**自己掐出来**的结果：时间、落宫、所问之事（自愿填写）
- 事后回来标注"应验/不应验"，形成个人复盘数据
- 软件只存不判，不生成任何统计性"准率"结论给用户施压

## 4. 北极星指标

- **激活（北极星）：毕业率**——新用户首次脱离引导、独立完成完整起课的比例
- 次级：D7 留存（每日一练拉动）、断语卡掌握度（50 格的正确率×速度）

## 5. 明确不做清单

| 不做 | 理由 |
|---|---|
| 排盘器 / "帮我算" | 违反宪法条款：软件不替人起课 |
| "今日运势"类内容 | 违反宪法条款：不预置针对个人的内容 |
| 账号系统 / 后端 | localStorage 够用，免费产品零成本运行 |
| 小程序 / 原生 App | 已决策：纯 Web 分发 |
| 进阶流派内容（江氏等） | v1 后再评估，与基础层明确切割 |
| "准确率"统计推送 | 避免对用户形成心理施压 |

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 内容合规（占卜类审核） | Web 分发免疫商店审核；全站措辞用"传统民俗文化教学" |
| 农历转换出错 | 成熟历法库 + 用万年历写死测试用例 |
| 时辰边界（如 14:59 vs 15:01） | 练习题显式展示当前时辰及剩余时间 |
| 留存短板（无工具钩子） | 靠每日一练习惯 + 断语掌握进度 + 后续进阶课程更新 |
| 获客（无商店入口） | 短视频教学内容分发，虚拟手掌动画即广告素材 |

## 7. 里程碑

- **第 1–2 周**：起课引擎 + 虚拟手掌 + 课程区 → **能学**
- **第 3 周**：题库（含错题本、段位测试）+ 断语卡 + 记录本 → **能刷**
- **第 4 周**：抛光、合规文案、上线 → **能传**

## 8. 与六爻平台的关系

- 共用组件：题库引擎、速查卡、记录本、（后续）SRS
- 小六壬 = 平台 v0（小体量验证），六爻 = 旗舰内容
- 品牌方向："掐指"系列，传统术数免费教学工具
