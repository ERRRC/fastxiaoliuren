# 小六壬题库 · 接口说明（给出题 AI）

> 你的任务：为"掐指 · 小六壬入门"教学软件开发题库第一批 JSON。
> 本文档包含全部数据源、引擎 API、题目格式和出题守则。

## 一、项目背景（30 秒）

- 产品：小六壬**教学**软件，免费、纯 Web。产品原则："教你算，不替你算"——所有题目以**传统文献知识**的身份出题，考"传统断语怎么说"，**绝不**替人断事。
- 完整方案见 `docs/产品方案-v1.0.md`；六爻版总方案（题库 JSON 结构的源头）见 `（姊妹项目方案，未随本仓库发布）`。
- 原型已就绪：`仓库根目录\`（引擎已测试通过，17/17 锚点全绿）。

## 二、权威数据源

**`仓库根目录\palaces.json`** —— 六宫数据，出题一律以此为准。

|---|---|---|---|---|---|---|
| 0 | 大安 | 食指根部 | 木 | 青龙 | 吉 | 安稳·平静·事缓·不动 |
| 1 | 留连 | 食指指尖 | 水 | 玄武 | 凶（暗昧迟滞） | 拖延·纠缠·事难成·阴人 |
| 2 | 速喜 | 中指指尖 | 火 | 朱雀 | 吉 | 喜事·快速·文书·消息 |
| 3 | 赤口 | 无名指指尖 | 金 | 白虎 | 凶（口舌是非） | 口舌·争执·官非·惊慌 |
| 4 | 小吉 | 无名指根部 | 水 | 六合 | 吉 | 和合·吉利·商量·小得 |

## 三、起课引擎 API（engine.js）

```js
XLR.computePalaces(lunarMonth, lunarDay, shichenIdx)
// → { monthPalace, dayPalace, hourPalace }  值为 0-5，对应 palaces 下标
// 规则：月宫=(月−1)%6；日宫=(月宫+日−1)%6；时宫=(日宫+时辰序)%6
XLR.shichenIndex(hour)   // 0-23 小时 → 时辰序 0-11（子=0，23点与0点同为子）
XLR.solar2lunar(y, m, d) // → { month, day, isLeap, monthCn, dayCn, ... }（闰月按本月数）
```

**注意：章节四"起课计算"由程序在运行时用引擎无限生成，你不需要出这一章的题。** 你的范围是下面的人工题章节。

## 四、你的任务：约 135 道人工题

| 章节 | 内容 | 题量 | 题型建议 |
|---|---|---|---|
| 1. 六宫基础 | 宫名、顺序、指节位置、总象 | ~30 | 单选、判断 |
| 2. 宫位属性 | 五行配属、六神配属 | ~25 | 单选、判断（正向+反向问） |
| 3. 断语口诀 | verse 原句、topics 分事类象 | ~50 | 单选（正向"速喜问求财断语是"+反向"'失物在坤方'出自哪宫"）、判断 |
| 5. 情景判断 | 教材式情景题（"某人测失物落赤口，按传统断语宜？"） | ~30 | 单选 |

### 题目 JSON Schema

```json
{
  "id": "c1-0001",
  "type": "single",
  "chapter": "六宫基础",
  "tags": ["宫序"],
  "difficulty": 1,
  "stem": "掐指路线上，紧排在「大安」之后的宫位是？",
  "options": ["留连", "速喜", "赤口", "小吉"],
  "answer": [0],
  "explanation": "六宫顺序：大安→留连→速喜→赤口→小吉→空亡。大安之后是留连。",
  "source": "诸葛马前课通行本"
}
```

字段约定：
- `id`：`c1-` 到 `c5-` 前缀 + 四位序号（c4 为程序生成章，跳过不用）
- `type`：`single`（单选）| `judge`（判断，options 固定 `["正确","错误"]`）| `multi`（多选，answer 为数组）
- `chapter`：`六宫基础` | `宫位属性` | `断语口诀` | `情景判断`（情景题也归入此章名下用 c5 前缀）
- `difficulty`：1-3（1=直接记忆，2=需区分易混项，3=需综合两条以上知识）
- `answer`：正确选项的**下标数组**
- `explanation`：必须引用口诀原句或 palaces.json 中的依据
- `source`：固定写 `诸葛马前课通行本`

## 五、出题守则（产品宪法，违反即废题）

1. **文献口吻**：题干问"传统断语/通行说法/口诀中怎么说"，不问"你应该怎么做"。
2. **中性表述**：不用"你"出题；情景题用"某人/行人/来问者"。
3. **不替人断事**：不出"落赤口这天该不该出门"这类替人做决策的题；只考断语内容本身。
4. **数据为准**：所有断语、五行、六神以 `palaces.json` 为准；解析引用原句。
5. **干扰项设计**：错项优先取"真实易混点"（如：留连/小吉都属水；失物'坤方'大安小吉都提过；申未午只属速喜），不用明显胡说的选项凑数。
6. **覆盖均衡**：六宫每宫题量大致均等；正向问与反向问都要有。

## 六、交付方式

- 输出为一个文件：`仓库根目录\questions\questions.json`，内容为题目对象数组（顶层就是数组，不要包壳）。
- 完成后在文件顶部不用加注释（JSON 不支持注释），元信息以每题字段自足。
- 自检：交付前请核对 (a) 总题数 ≥130；(b) 每题 options 长度 4（judge 为 2）；(c) answer 下标均在范围内且各题正确答案不集中于同一位置；(d) 六宫出现次数大致均等。
