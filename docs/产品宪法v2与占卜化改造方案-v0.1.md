# 产品宪法 v2 与占卜化改造方案 v0.1

前提：2026-09-04 三项决策 —— ① 输入形态「选择为主 + 可选备忘」；② 高危事类「保留但强制提示」；③ 定位「变成真正的占卜工具，教学降为附属」。

---

## 一、这次定位变更的真实含义

| 维度 | 教学工具（v1.x） | 占卜工具（v2.x） |
|---|---|---|
| 默认入口 | 课程演示（34 步动画） | 起课（点两下出课） |
| 结果页措辞 | 「按通行本法，这一课的**教学解读**是……」 | 直接给断语 |
| 演示动画 | 首屏默认完整播放 | 默认简略，完整版下沉到「学习」 |
| 教学资产 | 主体 | 降为「学习」Tab，保留不删 |
| 用户心智 | 我在学一个东西 | 我用它看一件事 |

**结论：深化方案 v0.1 的模块 A（三宫课式）与模块 B（四步断课）不废，反而升级为占卜结果页的主体。** 占卜工具对"断得深"的要求比教学工具更高——只给落宫一句话的占卜工具没人用。

**"选择为主"与"占卜工具"不冲突**：点两下选事类比自由输入更快，是更好的工具交互。观感差异来自结果页，不来自输入框。

## 二、产品宪法 v2（草案，替换原第 1 条）

### 原宪法（v1）
> 禁止"输入问题→输出吉凶"、禁止今日运势、断语必须能溯源到 `palaces.json`。

问题：把"按事类查断语"也误伤了——那本质是速查表的延伸，纯教学，无害。

### 新宪法（v2）

**1. 允许为具体事类出断语**
用户在预设事类中选定一项 → 系统给出该事类在这一课上的通行断语。这是本产品的核心功能。

**2. 断语必须可溯源，不得杜撰**
- 单宫断语 → `palaces.js`
- 组合课断（三才/日加时/格局）→ `combos.json`
- 五行生克等推导内容 → 必须显式标注"编者按五行常法推导"，不得伪装成古法原文
- 不得使用"AI 分析""智能推断"等措辞暗示系统理解了用户的问题

**3. 禁止确定性预测与决策建议**
- 不得声称能预测未来事实（"一定能找到""必然破财"）
- 不得对医疗、投资、法律、人身安全给出决策建议
- 不得提供今日运势、每日宜忌这类无课式支撑的功能

**4. 高危事类强制提示**
疾病 / 投资 / 法律 三类，结果页顶部强制显示对应提示，不可关闭：

> ⚠️ 此为本法通行断语，不构成医疗建议。身体不适请及时就医，勿以占断延误诊治。
> ⚠️ 此为本法通行断语，不构成投资建议。投资决策请咨询持牌专业人士。
> ⚠️ 此为本法通行断语，不构成法律意见。涉法事项请咨询执业律师。

**5. 全站免责声明（固定，不可关闭）**
> 本应用断语摘自传统小六壬通行本，属民俗文化内容，不构成对任何具体事项的预测或决策建议。

**6. 诚实原则（新增，本宪法核心）**
小六壬的课式只由起课时间（或报数）决定，**用户所问之事不参与任何计算**。因此：
- 自由备忘文本只用于用户自己记录，系统不解析、不影响结果
- 界面不得暗示"系统理解了你的问题"——它只是按事类取用对应断语

**7. 教学资产保留**
269 题题库 + 完整演示动画继续保留，降为「学习」Tab。教学是本产品的护城河，不因定位变更而删除。

## 三、信息架构改造

### Tab 重排（5 → 4 + 下沉）

| # | Tab | 内容 | 变更 |
|---|---|---|---|
| 1 | **起课**（默认） | 选事类 → 起课 → 断语结果页 | 新，原「课程演示」改造 |
| 2 | **课例** | 存过的课 + 备忘 + 复盘标记 | 新，承接"可选备忘" |
| 3 | **学习** | 完整演示动画 + 题库 + 辨析 | 原「课程演示」完整版 + 「题库」降级合并 |
| 4 | **速查卡** | 六宫速查 + 时辰 + 事类对照 | 保留 |
| — | 引擎自检 | 下沉到「速查卡」底部 | 不再单独占 Tab |

「我来算」：仍按用户此前要求原样保留，移入「学习」Tab（它是练习功能，不是占卜功能）。

### 起课 Tab 单页流程

```
① 选事类（横向 chip，一次点选）
     求财 · 失物 · 行人 · 疾病⚠ · 官事⚠ · 出行 · 求谋 · 交易 · 婚姻 · 宅舍
     ↓
② 起课（默认当前时刻，可手动改月/日/时；默认简略模式直接跳三宫落点）
     ↓
③ 结果页
     ├ 所问：失物（丢了手机）        ← 含可选备忘
     ├ 课式：月宫(起因)·日宫(过程)·时宫(结局)
     ├ 断语：该事类在这三宫上的原文 + 白话
     ├ 推演：三才 → 日加时 → 格局 → 五行生克（可折叠）
     └ 免责声明 / 高危提示
     ↓
④ 存入课例（可选，可写一句话备忘）
```

### 演示动画的处理

- **起课 Tab**：默认「简略模式」，直接跳到三宫落点，不逐步数 34 步
- **首次使用**：引导播放一次完整动画，看完后记标记，之后默认简略
- **学习 Tab**：保留完整 34 步动画，供系统学习用

## 五、风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| **上架合规**（若上架） | 🔴 高 | 占卜类在国内安卓市场属敏感品类，个人开发者无资质上架成功率低。**需先确认当前政策**；自用/分享则无此风险 |
| 用户依赖断语做重大决策 | 🟠 中 | 宪法 §3 §4 §5：禁决策建议 + 高危强制提示 + 全站免责 |
| 定位变更导致老用户流失 | 🟠 中 | 「学习」Tab 完整保留教学内容，不是删除是降权 |
| 事类断语补齐的考证质量 | 🟠 中 | 每条必须带出处；考不到就降级为"本体系补注"并标注 |
| 定位稀释（教学价值淹没） | 🟡 低 | 宪法 §7 明确保留；题库 269 题是全项目最值钱资产 |

## 七、待确认（阻塞 v2.0 开工）

1. **这个 APK 要上架吗？** 决定免责声明做到什么程度、措辞多保守、以及要不要为合规牺牲功能。**自用/分享** → 按本方案执行；**上架** → 需先查当前政策，可能要调整。
2. **事类清单以哪一份为准？** 建议就用 `palaces.js.topics` 现有事类 + `MODERN_MAP` 的事类并集，但需你确认是否要增减（如婚姻、宅舍是否保留）。
3. **「可选备忘」存本地还是云端？** 建议 localStorage（按用户隔离），不联网，符合"双击 index.html 就能跑"。
